# A/B тест: новая страница оплаты

## Цель
Проверить, влияет ли новый экран оплаты на конверсию и выручку.

## Гипотеза
Новая страница оплаты увеличит конверсию в оплату на ≥5%.

## Метрики
- **CR (Conversion Rate)** для всех пользователей
- **CR** для пользователей, дошедших до страницы оплаты
- **Drop-off** после payment page
- **Средний чек (AOV)**
- **Выручка (Revenue)**
- **ARPU**

## Данные
- `data/users.csv` — пользователи и группы A/B
- `data/sessions.csv` — сессии и страницы
- `data/payments.csv` — платежи

- `sql/01_prepare_user_table.sql` — подготовка таблицы пользователей
- `sql/02_metrics.sql` — расчёт метрик
